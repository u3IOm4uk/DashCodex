## Реалізовано

- Локальний статичний dashboard без backend/build для runtime. Excel schema, книга/формули, null/0, source totals і явна `UNIT_HIERARCHY` збережені.
- **A01/A07/A08:** comparison workspace прокручується; chart host має узгоджену responsive-висоту; нативні мобільні фільтри підтримують клавіатуру, Escape і повернення фокусу. Допоміжний текст має вищий контраст і більший розмір.
- **A02:** router включає comparison та змінені specs; infrastructure diff запускає всі browser specs. Workflow споживає перелік router, перевіряє inline JS і використовує `npm ci`/lockfile.
- **A03/A04:** календарна validation блокує невалідну непорожню дату до прийняття книги, повідомляє sheet/row та зберігає попередню модель. Обидва UI застосовують пріоритет зміненої межі дат.
- **A05/R2:** `ContourSource` надає одну прийняту модель обом UI; нові імпорти відсікають старі асинхронні читання. Comparison не повторює parse й не скидає основне дерево при відкритті.
- **A06 / D31:** coverage-пояснення прибрано за вимогою користувача. Невизначені вузли, включно з `УВ "Курськ"`, доступні через «Приховані»; конфігурація й totals збережені.
- **R1:** bulk/reset і derived parent state перенесені з HTML у comparison; «Усі» виконує один render. Є generation guard chart lifecycle, явний navigation API замість глобального scroll wrapper, повторне використання number formatter.
- **V1–V3:** читабельніша композиція comparison, кольорові підписи вибраних серій із видаленням, стабільні кольори решти набору, базова дата/значення кожної серії й горизонталь 100. Tooltip містить індекс та абсолютне число, таблиця завжди абсолютна.
- Незалежні вікна основного/модального графіків, один sticky-ряд, FPV-вісь, hierarchy/direct-child details і локальні archive/status preferences збережені.

- **D31:** компактніші категорії зі зміною під числом і трендом праворуч; розділи над рядом, двобічні маски, зайві кнопки/пояснення прибрані. Один блок дати/періоду, вибір доби кліком графіка, кругла структура з виносками, баланс позицій. Мініграфік БпС вибирає тип; нижні панелі залишаються під картками під час складання й заходять під них лише за подальшого scroll.

## Перевірено для цієї реалізації

- **30/30 Playwright tests — PASS**, Chromium 140 (Playwright 1.55.0), штатний `playwright.config.cjs` і portable Node server. Охоплення: core, sticky, charts, БпС/FPV, units, comparison actions/tablet/audit.
- **7/7 Node unit tests — PASS:** календарні дати, пріоритет межі, прийняття/конкуренція джерел, quality routing.
- **Adapter regression — PASS:** контрольні totals/series/null/0, cache/import isolation, date policy, chart axes та view helpers.
- Syntax змінених first-party JS, inline syntax і resource revision v60 — PASS.
- Попередній аудит мав ручні ревізії трьох viewport. Поточний UI переглядався частково на desktop; фінальний візуальний перегляд усіх розмірів користувач бере на себе. Подальші візуальні перевірки зупинені за його прямою вказівкою. Автоматичні geometry checks включені у пройдений suite.
- Невалідний File API import перевірено автоматично: помилка містить рядок, попередні дані збережені. Новий валідний імпорт парситься один раз.

## Обмеження й наступні дії

GitHub Actions для цієї гілки ще не засвідчений: workflow запускається для PR і push у main; PR не створювався; fast-forward злиття виконане. Локальний повний suite пройшов. Mandatory branch protection не перевірена.

Safari/Firefox, фізичні пристрої, screen reader, OS reduced-motion emulation та великі книги не перевірені. Reduced-motion правила збережені. У контрольній книзі лишаються 910 помилок клітинок вартості ОВгП (не використовуються), невказана одиниця територій та неповне охоплення ієрархії. Acceptance policy для книги лише з персоналом/БК не розширена.
