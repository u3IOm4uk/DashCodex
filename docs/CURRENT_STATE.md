# Поточний стан

Оновлено: **2026-09-12**. Етап: локальний функціональний прототип КОНТУР у приватному GitHub-репозиторії. Офіційного semver немає; активні ресурси мають cache revision **28**.

## Реалізовано

- Статичний `index.html`, адаптер `contour-data.js`, UI-контролер `contour.js`, три активні CSS-шари; локальні Excel/шрифти/ApexCharts. Backend і persistence відсутні.
- Чотири розділи, імпорт/CSV, дати, картки, часові графіки, структура, таблиці, діалоги й попередження якості.
- Парні показники СОУ/противник і втрачено/відновлено; територіальний баланс; FPV відокремлений від інших типів БпС.
- Для обраної доби часові графіки мають контекст до 30 днів без розширення підсумків.
- Один sticky-ряд категорій плавно стискається без копій і spacer; зміна категорії повертає сторінку нагору зі збереженням розміру карток. На телефоні є drawer і нижня навігація.
- Сім типів БпС мають власні картки й локальні line/bar режими; деталі угруповання показують усі сім типів, багатовибірну легенду й окрему вісь FPV при спільному показі.
- При перетині меж дат поле, яке змінює користувач, має пріоритет; друга межа прирівнюється до нього. Однакові дати означають одну добу.
- Репозиторій очищено від неактивних MVC/Dexie-копій, ручних `versions/txt v*`, дубля `xlsx.js`, старого `css.css` і непідключеного Bootstrap; історія збережена в Git.
- Додані `.gitignore` і `.gitattributes`.
- `Запустити.cmd` більше не містить абсолютного шляху конкретного ПК: шукає Python 3 через `py -3`, `python` або `python3`, відкриває браузер і запускає сервер лише на `127.0.0.1:8080`.

## Останній релевантний статус перевірок

- JS syntax та адаптерні перевірки проходили успішно для revision 28; підсумки семи типів для 15 АК були звірені з книгою.
- Останні viewport-перевірки охоплювали 1440×1000, 1024×768 і 390×844; перевіряли sticky-картки, БпС, деталі, легенду, FPV-вісь, line/bar, Escape та повернення категорії нагору.
- Етап 1 не змінює `index.html`, `contour*.js` або активні CSS, тому функціональна поведінка runtime не повинна змінитися.
- Повного автоматичного browser-suite і CI поки немає.

Детальна історія попередніх ревізій і перевірок не є робочим контекстом і зберігається в `.audit/REVISIONS.md` та Git-історії.

## Відомі обмеження й технічний борг

- CSS містить overrides і неактивні селектори; приховані sidebar і старий donut-контейнер залишаються в DOM/коді.
- UI монолітний і повторює частину агрегацій; продуктивність великої книги не профільована.
- Помилки рендеру графіків не мають окремого UI-повідомлення.
- Частковий розподіл за наявними значеннями не пояснений окремо.
- Одиниця територій не підтверджена; у вартості ОВгП є помилки джерела; формули Excel не перераховуються.
- Межа ручного діапазону й поведінка «увесь період» мають різні технічні обмеження.
- Діалог «Джерело» на desktop не має звичайної видимої кнопки після приховування sidebar.
