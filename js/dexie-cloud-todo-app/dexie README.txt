Ось детальний перелік основних методів бібліотеки Dexie.js для роботи з базою даних, розбитий за категоріями для швидкого пошуку.
Усі асинхронні методи повертають JavaScript Promise, тому з ними зручно працювати через await або .then().
------------------------------
## 1. Ініціалізація та керування БД
Методи для створення структури та підключення до бази.

* new Dexie(dbName) — створення нового екземпляра бази даних.
* db.version(x).stores({...) — визначення версії бази та схеми таблиць (індексів).
* db.open() — відкриття з'єднання з базою даних (зазвичай викликається автоматично).
* db.close() — закриття з'єднання з базою.
* db.delete() — повне видалення бази даних із браузера.

------------------------------
## 2. Додавання та оновлення даних (Create / Update)
Ці методи викликаються на конкретній таблиці, наприклад: db.friends.add(...).

* add(item, [key]) — додавання нового об'єкта. Якщо об'єкт із таким id вже є — виникне помилка.
* bulkAdd([items]) — швидке додавання масиву об'єктів за один раз.
* put(item, [key]) — додавання або оновлення. Якщо об'єкта немає — додасть, якщо є — перезапише повністю.
* bulkPut([items]) — масове додавання або перезапис масиву об'єктів.
* update(key, changes) — часткове оновлення об'єкта (змінює лише вказані поля, інші не чіпає).

------------------------------
## 3. Читання даних за ключем (Read)

* get(key) — пошук та отримання одного об'єкта за його первинним ключем (id).
* bulkGet([keys]) — отримання масиву об'єктів за масивом їхніх ключів.
* toArray() — вивантаження абсолютно всіх об'єктів із таблиці у вигляді звичайного масиву.

------------------------------
## 4. Видалення даних (Delete)

* delete(key) — видалення одного об'єкта за його ключем.
* bulkDelete([keys]) — масове видалення об'єктів за списком ключів.
* clear() — повне очищення таблиці (видаляє всі записи, але зберігає саму таблицю).

------------------------------
## 5. Пошук, фільтрація та запити (Queries)
Для складного пошуку використовуються методи where(), які повертають об'єкт колекції.

* where(index) — початок вибірки за певним індексованим полем.
* .equals(value) — пошук точного збігу (наприклад: where('age').equals(25)).
* .above(value) / .below(value) — значення більше або менше вказаного.
* .between(lower, upper) — значення в діапазоні (включаючи lower, але виключаючи upper).
* .startsWith(string) — пошук рядків, що починаються з вказаних літер (корисно для автокомпліту).
* .anyOf([val1, val2]) — пошук елементів, які збігаються з будь-яким значенням із масиву.
* .filter(fn) — тонка фільтрація за допомогою кастомної функції (працює повільніше, ніж індекси).

------------------------------
## 6. Модифікація результатів вибірки
Методи, які додаються в кінець ланцюжка запиту перед отриманням результату.

* .limit(number) — обмеження кількості результатів (корисно для пагінації).
* .offset(number) — пропуск перших N результатів.
* .reverse() — розгортання порядку сортування у зворотному напрямку.
* .sortBy(index) — сортування результатів за вказаним індексом.
* .count() — підрахунок кількості знайдених елементів без завантаження їх у пам'ять.

------------------------------
## 7. Транзакції (Transactions)

* db.transaction(mode, tables, callback) — об'єднання кількох операцій в одну транзакцію (наприклад, для безпечного переказу коштів чи синхронізації, де або виконується все, або нічого у разі помилки).

Який із цих методів ви хочете розібрати на практичному прикладі коду? Ми можемо написати динамічний пошук (фільтрацію за текстом) або реалізувати масове оновлення/видалення записів.
