# Інструкції для агента

Цей файл є основною точкою входу для роботи з репозиторієм.

## Обов'язкове завантаження правил

На початку кожної нової сесії, перед аналізом, плануванням або внесенням змін:

1. Прочитай `.agent/GENERAL.md`.
2. Прочитай `.agent/PROJECT.md`.
3. Застосовуй обидва набори правил протягом усієї сесії.

Не починай виконання завдання, доки обидва файли не прочитані.

## Пріоритет інструкцій

Якщо правила суперечать одне одному, використовуй такий порядок пріоритету:

1. Остання пряма вказівка користувача.
2. `.agent/PROJECT.md` — правила конкретного проєкту.
3. `.agent/GENERAL.md` — загальні правила роботи агента.

Специфічне правило проєкту уточнює або перевизначає загальне правило лише в межах цього проєкту.

Якщо правила не суперечать одне одному — застосовуй їх одночасно.

## Робота з контекстом

Після завантаження правил:

1. Дотримуйся порядку завантаження контексту, визначеного в `.agent/PROJECT.md`.
2. Відкривай лише документацію та код, потрібні для поточного завдання.
3. Не завантажуй весь репозиторій або всю документацію без необхідності.
4. Якщо для конкретної теми в `.agent/PROJECT.md` визначене джерело істини, використовуй саме його.

## Загальний принцип

`.agent/GENERAL.md` визначає **як працювати**.

`.agent/PROJECT.md` визначає **як працювати саме з цим проєктом**.

Проєктні правила не потрібно дублювати в загальних, а загальні правила не потрібно повторювати в проєктних без необхідності їх уточнення або перевизначення.
